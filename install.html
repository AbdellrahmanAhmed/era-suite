الحالة

المساحة المشتركة

هذه النسخة مربوطة تلقائيًا بمساحة قسم التركيبات المشتركة era-instl.
كل تسجيل بيتزامن مع باقي الفريق أوتوماتيك — مش محتاج تعمل أي إعداد.
لو المزامنة وقفت لأي سبب، اضغط "🔄 مزامنة دلوقتي" فوق.

خطوات الإعداد — مرة واحدة

1. افتح console.firebase.google.com واعمل مشروع جديد (مجاني).
2. من Build → Firestore Database اضغط Create database واختار Production mode.
3. من Build → Authentication → Sign-in method فعّل Anonymous.
4. من Project settings → Your apps اختار Web (</>) وانسخ الـ firebaseConfig والصقه فوق.
5. من Firestore → Rules حط ده واضغط Publish: 
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /workspaces/{ws}/entries/{doc} {
      allow read, write: if request.auth != null;
    }
  }
}
6. على الموبايل والكمبيوتر: افتح نفس الملف، حط نفس كود المساحة ونفس الإعدادات → تفعيل.
⚠️ خلي كود المساحة طويل وعشوائي — هو اللي بيحمي بياناتك.
